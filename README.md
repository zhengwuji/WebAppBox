<h1 align="center">WebAppBox 多开网页盒子</h1>

<p align="center">把任何网站变成可多开、带独立指纹环境的桌面应用 · 基于 Electron · 完全开源免费</p>

## ✨ 功能特性

- 🔥 **一键网页转应用**：将任何网站变成独立的桌面应用，图标化侧边栏管理
- 👥 **账号多开**：每个站点（含每次多开）独立会话，账号隔离互不干扰
- 🛡 **指纹环境**：每个环境一套独立指纹（操作系统 / Chrome 版本 / 时区 / 地理位置 / 屏幕 / 硬件 / WebGL / 字体 / Canvas·WebGL·音频噪声 / 媒体设备 / 电池 / 语音），支持一键随机化与手动固定
- 🌐 **代理**：全局代理 + 每站点覆盖，支持 SOCKS5 / HTTP 及用户名密码认证；一键测试连通性并显示出口 IP、国家、城市、ISP、延迟
- ⚡️ **闪电切换**：全局快捷键呼出/隐藏（默认 `Ctrl + H`），关闭即最小化到托盘
- 🧩 **内核管理**：在线选择并下载 Electron 内核（SHA256 校验、暂存、重启应用、一键还原）
- 🎨 **深度定制**：自定义窗口尺寸、图标、JS 注入、站点分组
- 📋 **剪贴板历史**：文本 / 图片 / 文件自动记录，支持置顶、收藏、搜索
- 🧩 **插件系统**：内置插件市场，支持本地安装
- 🔒 **隐私保护**：全部数据本地存储，不上云

## 🚀 使用说明

### 安装

到 [Releases](https://github.com/zhengwuji/WebAppBox/releases) 下载最新的 `WebAppBox-Setup-*.exe`，双击安装即可。

### 基本使用

1. **添加站点**：填入网站地址与名称即可，`www.google.com` 这类不带协议的地址会自动补全 `https://`
2. **新增浏览器**：站点管理第一个按钮，创建独立浏览器环境——独立会话、独立指纹、独立代理、可按环境挂载扩展；打开后从起始页输入网址上网，反复添加等同多台全新浏览器
3. **打开站点**：单击图标打开；按住 `Ctrl` 单击可多开一个独立实例
4. **呼出/隐藏**：`Ctrl + H` 全局呼出或隐藏窗口；关闭按钮默认隐藏到托盘
5. **站点代理**：站点编辑抽屉内可选「跟随全局 / 直连 / 自定义」，自定义支持 SOCKS5/HTTP + 用户名密码，可测试连接并显示出口 IP 与国家
6. **站点分组**：可将多个站点打包为一组，快捷键整组切换

### 指纹环境（设置 → 指纹环境）

- 每个站点首次打开时自动生成一套独立、自洽的指纹并持久保存
- **随机化新身份**：一键重新生成（保存后重新打开站点生效）
- **手动固定**：操作系统、Chrome 版本、时区（联动语言与地理位置）、CPU 核数、内存、屏幕分辨率/缩放、WebGL 显卡
- 每次多开的实例也拥有各自的独立指纹

### 代理（设置 → 指纹环境）

- **全局代理**：作用于主窗口、图标抓取、更新检查等默认会话
- **站点代理**：每站点可选「跟随全局 / 直连 / 自定义」
- 自定义支持 SOCKS5 / HTTP，可填用户名密码
- **测试连接**：立即验证代理可用性，成功后显示出口 IP、国家（地区）、城市、ISP、延迟
- 说明：带密码的 SOCKS5 会自动经本地中继转发（Chromium 内核原生不支持 SOCKS5 认证）

### 内核管理（设置 → 指纹环境 → 内核管理）

1. 选择 Electron 内核版本 → **下载并暂存**（自动 SHA256 校验）
2. **应用暂存内核并重启**：退出应用后自动替换内核文件并重新启动
3. 替换前自动备份当前内核，可用 **还原备份内核** 一键回滚
4. 各站点指纹中的 Chrome 版本在「环境指纹」里单独选择，与内核替换互不影响

### 默认快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + H` | 隐藏 / 显示 主窗口 |
| `Ctrl + B` | 隐藏 / 显示 侧边导航 |
| `Ctrl + S` | 打开设置 |
| `Ctrl + Tab` | 切换站点 |
| `Ctrl + ~` | 切换分组 |
| `Ctrl + T` | 窗口置顶 |
| `Ctrl + Q` | 退出软件 |

（快捷键均可在「改快捷键」页面自定义）

### 数据存储位置

- 数据库与配置：`%APPDATA%/WebAppBox`
- 便携版：程序目录下 `webappbox-user-data`

## 🛠 本地构建

```bash
pnpm install
pnpm exec electron-vite build        # 构建主进程
cd gui/setting && npx vite build     # 构建设置界面
cd ../..
pnpm run build --win                 # Windows 安装包（--mac / --linux 同理）
```
